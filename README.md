# Garden of Memories

Minimal HTML5 prototype for the redesigned level map.

## Current state

The screen contains only three level sprites arranged on one vertical line:

- level_1.png — completed level
- level_2.png — current level
- level_3.png — locked level

The completed level is at the bottom, the current level is above it, and the locked level is at the top.

No UI, buttons, popups, or other gameplay systems are included yet.
