# Внешние ассеты

В проект добавлены локальные PNG-ассеты из публичного репозитория Kenney CC0, чтобы они работали без запросов к внешним CDN во время игры.

## Растения
- `plants/flower-red.png` — Kenney, Abstract Platformer / `plantTop_red.png`
- `plants/flower-yellow.png` — Kenney, Abstract Platformer / `plantTop_yellow.png`
- `plants/flower-blue.png` — Kenney, Abstract Platformer / `plantTop_blue.png`
- `plants/leaf.png` — Kenney, Abstract Platformer / `plantTop_leaves.png`
- `plants/plant-purple.png` — Kenney, Platformer Assets Base / `plantPurple.png`

## UI
- `ui/button-green.png` — Kenney UI Pack, Green / Double / `button_rectangle_flat.png`
- `ui/button-round-green.png` — Kenney UI Pack, Green / Double / `button_round_flat.png`
- `ui/star.png` — Kenney UI Pack, Green / Double / `star.png`
- `ui/arrow-right.png` — Kenney UI Pack, Green / Double / `arrow_basic_e.png`

## Источник и лицензия
Источник файлов: [shorepine/kenney на GitHub](https://github.com/shorepine/kenney). Репозиторий указывает, что ассеты Kenney распространяются по лицензии **CC0 1.0**; разрешено коммерческое использование без обязательной атрибуции. Поддержать автора можно на [kenney.nl/donate](https://kenney.nl/donate).

Перед релизом рекомендуется сохранить копию лицензии из исходного репозитория и повторно проверить лицензию выбранных файлов.
